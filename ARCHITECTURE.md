# BHARATH SENTINEL — Technical Architecture & System Blueprint
**Autonomous Ocean Observation Platform | SIH 2026 (Problem Statement 26065)**

---

## 📌 EXECUTIVE SUMMARY

The **BHARATH SENTINEL Autonomous Ocean Observation Platform** is a multi-tier, real-time software system designed for autonomous vessel navigation, multi-sensor oceanographic/atmospheric observation, hardware-in-the-loop (HIL) simulation, and AI-driven scientific climate forecasting in the Southern Ocean.

The system features:
- **Asynchronous Microservice Architecture**: Driven by Python FastAPI, AsyncIO background tick loops, and WebSockets.
- **Geospatial WebGL Visualization**: MapLibre GL JS engine with 100% native GeoJSON map layers anchored to exact 64-bit coordinates.
- **Autonomous Safety Finite State Machine (FSM)**: Manages 11 vessel operational states, automatic shutter payload control, and hazard recovery modes.
- **AI Scientific Prediction Engine**: Time-series forecasting (Holt-Winters, Linear Trend Regression), anomaly detection (Isolation Forest), and baseline reference modeling against global datasets (Copernicus Marine, Argo, ERA5, NOAA WOD, NASA OceanColor).

## 🔄 2. DETAILED DATA & CONTROL PIPELINES

### 2.1 Ingestion & Sensor Categorization
Telemetry originates from physical microcontrollers via the Hardware Abstraction Layer ([base.py](file:///d:/sih%20updated/aurora/backend/app/hal/base.py)) or the internal physics simulator ([engine.py](file:///d:/sih%20updated/aurora/backend/app/simulation/engine.py)).
Sensors are strictly categorized into two main groups:
1. **Oceanographic Sensors**: Water Temperature ($^\circ\text{C}$), Salinity ($PSU$), Dissolved Oxygen ($mg/L$), $pH$, Turbidity ($NTU$), Depth ($m$).
2. **Atmospheric Sensors**: Air Temperature ($^\circ\text{C}$), Barometric Pressure ($hPa$), Relative Humidity ($\%$), Wind Speed ($m/s$), Wind Direction ($^\circ$).

### 2.2 Safety State Machine & Automated Protection
The [state_machine.py](file:///d:/sih%20updated/aurora/backend/app/services/state_machine.py) finite state machine evaluates triggers every tick loop:
- **Operational States**: `IDLE`, `MISSION_START`, `NORMAL_OPERATION`, `WARNING`, `OBSTACLE_AVOIDANCE`, `ADAPTIVE_SAMPLING`, `LOW_BATTERY`, `SHUTTER_CLOSING`, `SAFE_MODE`, `RECOVERY`, `FAULT`.
- **Payload Shutter Actuator**: `OPEN`, `OPENING`, `CLOSING`, `CLOSED`, `FAULT`.
- **Automatic Hazard Protection**: Water ingress (leak detection), low battery ($<10\%$), or sensor health average below threshold ($<30\%$) forces the state machine to transition to `SAFE_MODE` and triggers protective shutter closure.

### 2.3 Navigation & Collision Avoidance
- **Lawnmower Coverage**: Generated by [coverage_path.py](file:///d:/sih%20updated/aurora/backend/app/algorithms/coverage_path.py) using Boustrophedon geometric sweep lines clipped to circular geofence polygons.
- **Evasive Turn Vectoring**: Computed by [obstacle_avoidance.py](file:///d:/sih%20updated/aurora/backend/app/algorithms/obstacle_avoidance.py). Evaluates ice floe distances ($d_{obs}$) into `SAFE` ($>100\text{m}$), `WARNING` ($50-100\text{m}$), and `CRITICAL` ($<50\text{m}$) zones, dynamically picking perpendicular escape headings.

### 2.4 Data Persistence & Real-Time Broadcast
- Telemetry, ocean readings, atmospheric conditions, battery status, anomalies, and events are stored asynchronously in PostgreSQL 16 + PostGIS ([models.py](file:///d:/sih%20updated/aurora/backend/app/database/models.py)).
- The [websocket_manager.py](file:///d:/sih%20updated/aurora/backend/app/services/websocket_manager.py) broadcasts real-time JSON frames to React clients.
- The map module ([AuroraMap.tsx](file:///d:/sih%20updated/aurora/frontend/src/components/map/AuroraMap.tsx)) renders vessels, observation radii, coverage routes, and ice floes using native MapLibre GeoJSON WebGL canvas layers.

## 🌐 4. DATA SOURCES & SCIENTIFIC BASELINES

1. **ASV Payload Telemetry**: Real-time physical/simulated sensors, BMS battery metrics, NMEA-0183 GPS/kinematics, leak sensors, and optical shutter state feedback.
2. **Copernicus Marine Service (CMEMS)**: Satellite Sea Surface Temperature ($SST$) and Chlorophyll-$a$ / $CDOM$ datasets providing regional ocean baselines.
3. **Argo & BGC-Argo Global Profiling Array**: In-situ CTD temperature, salinity ($PSU$), dissolved oxygen ($DO$), and $pH$ vertical ocean profiles.
4. **ERA5 Atmospheric Reanalysis (ECMWF)**: Surface barometric pressure ($hPa$), air temperature, relative humidity, and wind vector baselines.
5. **NOAA World Ocean Database (WOD) & NASA OceanColor**: Historical ocean chemistry, turbidity, and spectral reflectance baselines.

## 🧮 5. ALGORITHMS & MATHEMATICAL FORMULATION

### 5.1 Navigation & PID Heading Control
- **Haversine Distance**:
  $$d = 2R \arcsin\left(\sqrt{\sin^2\left(\frac{\Delta \phi}{2}\right) + \cos(\phi_1)\cos(\phi_2)\sin^2\left(\frac{\Delta \lambda}{2}\right)}\right)$$
- **Forward Azimuth Bearing**:
  $$\theta = \text{atan2}\left(\sin(\Delta \lambda)\cos(\phi_2), \; \cos(\phi_1)\sin(\phi_2) - \sin(\phi_1)\cos(\phi_2)\cos(\Delta \lambda)\right)$$
- **Differential Thrust PID Controller**:
  $$u(t) = K_p e_\theta(t) + K_i \int_0^t e_\theta(\tau) d\tau + K_d \frac{de_\theta(t)}{dt}$$

### 5.2 Geometric Path Generation
- **Boustrophedon Sweep Pattern**:
  Generating parallel horizontal lines spaced by $d = 400\text{ m}$ clipped inside circular geofence polygons ($R = 2500\text{ m}$) via Shapely geometry intersections (`Polygon.intersection(LineString)`).

### 5.3 Obstacle Avoidance Vectoring
- **Perpendicular Turn-Away Vectoring**:
  Evaluates obstacle ranges ($d_{obs}$). If $d_{obs} < 100\text{ m}$, candidate escape headings ($\theta_{obs} \pm 90^\circ$) are calculated, picking the turn requiring minimal heading alteration.

### 5.4 AI Climate & Prediction Models ([climate_engine.py](file:///d:/sih%20updated/aurora/backend/app/ai/climate_engine.py))
- **Holt-Winters Exponential Smoothing & Linear Trend Regression**:
  Forecasts 12-step future horizons for **Ocean Warming**, **Acidification** ($pH$), **Deoxygenation** ($DO$), and **Salinity** ($PSU$) with $95\%$ confidence bounds ($\text{Predicted} \pm \sigma$).
- **Isolation Forest Multivariate Anomaly Classifier**:
  Unsupervised multi-sensor anomaly scoring detecting SST warming spikes ($\Delta T \ge +1.5^\circ\text{C}$), hypoxia alerts ($DO \le 2.0\text{ mg/L}$), and acidification drops ($pH \le 7.8$).
- **Entropy-Based Adaptive Sampling**:
  Dynamically increases vessel sampling frequency and waypoint density upon detecting active environmental anomalies.
